Web Tools · add a tool

Turn a web page into a tool.

Fill this in, then open Web Tools on the phone, tap ADD, then SCAN, and point it here. Nothing leaves this page; the code is drawn in your browser.

1   On the phone: Web Tools → ADD → SCAN.
2   Hold the phone up to the code. It reads it and shows the tool's page.
3   Tap OPEN. The site logs in and behaves like it does in any browser, and stays inside the sites listed above.

Web Tools is on BrightMarket and GitHub.

Bring a login from this computer

Sign in here, carry it over by code.

Web Tools runs Firefox's engine, and most sign-in pages take it for the browser it is. A few (Ticketmaster runs reCAPTCHA Enterprise and a fingerprint check on its login) still refuse. For those, sign in on this computer and hand the phone the session: the cookies travel in the code, compressed, and the tool opens already signed in. Nothing leaves this page.

1   Sign in to the site in this browser.
2   Open DevTools (F12 or ⌥⌘I) → Network. Reload the page. Click the first request to the site.
3   Right-click it → Copy → Copy as cURL. Paste below.

On the phone: ADD → SCAN, then scan the parts in order. Sessions expire the way they do in a browser; when the site asks you to sign in again, make a new code.
